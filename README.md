# Controle de Estoque em Python

Sistema simples de cadastro e consulta de produtos, desenvolvido em Python.

## Funcionalidades
- ✅ Adicionar produtos com nome, quantidade e preço
- ✅ Visualizar todos os produtos cadastrados
- ✅ Calcular valor total por produto

## Como usar
Execute no terminal:
python estoque.py
